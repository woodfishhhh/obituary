# 讣告 1.5.0

- 命令行、Windows 托盘、小窗口和资源管理器菜单现在共用同一个语言设置。可以跟随系统，也可以指定英文或简体中文。
- Windows 小窗口以 GB 或 TB 显示大小时保留两位小数，例如 `1.30 GB`；MB 及以下的显示不变。
- 修复了日历弹窗顶部线条在圆角处突出的显示问题。
- 新增匿名使用统计，默认开启，可用 `obit config telemetry off` 关闭；详情见[隐私政策](https://obituary.woodfish.site/docs/privacy.html)。

# Obituary 1.5.0

- The CLI, Windows tray, desktop window and File Explorer menu now share one language setting. Follow your system language or select English or Simplified Chinese.
- The Windows desktop window shows two decimal places for sizes in GB or TB, such as `1.30 GB`. Sizes in MB and below are unchanged.
- The top line of the calendar dialog now follows its rounded corners.
- Anonymous usage statistics are on by default. To turn them off, run `obit config telemetry off`. See the [privacy policy](https://obituary.woodfish.site/docs/privacy.html).
