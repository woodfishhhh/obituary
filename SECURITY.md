# 安全问题 / Security

讣告会移动和删除文件，所以任何可能误删、移错位置、越过保留期或越权的问题都按安全问题处理。

请不要公开提 issue。在 GitHub 上打开本仓库的 **Security → Report a vulnerability**，私下报告：怎么复现、影响到哪些文件、用的是哪个版本（`obit --version`）。收到后会先确认，修好发版后再公开细节。

---

Obituary moves and deletes files, so anything that could delete the wrong thing, move it to the wrong place, skip the retention period or act without permission is treated as a security problem.

Please don't open a public issue. Use **Security → Report a vulnerability** on this repository to report it privately: how to reproduce it, which files it affects, and your version (`obit --version`). You'll get an acknowledgement first; details are published after a fixed release is out.
