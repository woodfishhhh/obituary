# 国际化

CLI 和托盘使用 `internal/i18n`。先在 `messages.go` 定义稳定消息 ID 和英文默认文案，再更新语言目录并检查占位符。语言选择依次尊重显式覆盖、配置和环境；不要把繁体标签归到简体中文。MCP 工具名、JSON 字段、退出码、命令、日志标记和 hook 的宿主协议保持原样。

官网的语言清单在 `site/landing/src/locales.ts`。首页的每份文案要与简中类型一致。用户手册的十种语言各有自己的页面和 agent 指南；开发文档只有简中和英文，其余导航进入英文开发区。不要为凑齐语言集合而复制英文页面。

README 的英文正文在仓库根目录 `README.md`。图解文字在 `docs/assets/readme/i18n/strings.json`，修改后重新生成浅色、深色图，按 `docs/README.md` 的步骤检查布局、链接和图片路径。网站的翻译、生成页和语言互链则由两套[网站构建](./build-test)检查。
