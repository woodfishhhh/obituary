# 文件夹策略

给一个文件夹设策略后，放进来的文件各自按寿命下葬。最常见的是下载文件夹：

```powershell
obit watch C:\Users\你\Downloads 2w          # 放进来的每样东西两周后进墓地
obit watch --list                           # 有哪些文件夹策略，各自的豁免和安静期
obit watch --remove C:\Users\你\Downloads    # 移除策略，它登记过的寿命一起取消
```

## 怎么生效

- **策略本身要你批准。** `obit watch` 先生成提议，`obit approve` 或在小窗口「待你决定」里批准后才生效。
- **安静 10 分钟才动手。** 文件到期、并且安静 10 分钟没被改动后，才自动下葬。
- **子文件夹另出提议。** 子文件夹到期时只生成提议，等你批准才下葬。
- 移除策略时，它登记过的寿命一起取消。

## 资源管理器里的日期

下载、桌面和文件夹策略管的目录里，被跟踪的东西在资源管理器里显示成「名字（11-13 下葬）」，真实文件名不变。

- 日期靠文件夹里隐藏的 `desktop.ini`。
- `config.toml` 的 `[explorer]` 可以关掉（`enabled = false`）或扩大到其他位置（`everywhere = true`）。
- 资源管理器有自己的缓存，延长寿命后同一个窗口最长约一分钟还显示旧日期。
