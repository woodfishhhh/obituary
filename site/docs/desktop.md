# 小窗口、托盘和右键菜单

不会用命令行，也能复活文件、批准提议、改设置。

## macOS 小窗口和菜单栏图标

从同一个发布版本下载通用 macOS DMG 和 checksums.txt。先核对 SHA-256，再打开 DMG，把 Obituary.app 拖到「应用程序」或用户的 Applications 文件夹；启用登录启动前先弹出 DMG。

这个 app 里有 Wails 小窗口、菜单栏图标，以及配套的 obit 和 obitd。每 5 分钟运行一次的 launchd 用户代理仍是独立的兜底任务。在设置页打开「随登录启动托盘」会安装讣告自己的用户 LaunchAgent；关闭它只会移除这一项。

移除 `Obituary.app` 不会删除用户数据。默认目录是 `~/Library/Application Support/obituary/`：`store.json` 是账本，`config.toml` 是设置，同卷下葬的文件保留在 `graveyard/`。

### 第一次打开未签名 app

这个发布包没有 Developer ID 签名，也没有公证。确认下载自可信发布页并核对 SHA-256 后，先尝试打开一次。如果 macOS 提示无法验证开发者，打开「系统设置 → 隐私与安全性」，在讣告对应位置选择「仍要打开」，确认系统提示后再打开。不要全局关闭 Gatekeeper，也不要递归清除隔离属性；如果系统报告 app 已损坏、包含恶意软件，或公司策略禁止放行，请停止。

### Homebrew Cask 方案

Cask 应安装同一个通用 DMG，把 Obituary.app 复制到「应用程序」，并从 app bundle 提供 obit 和 obitd。在桌面 DMG 有稳定发布地址并完成卸载回执复核前，现有 CLI 压缩包 cask 与桌面 cask 分开。
## Ubuntu 24.04（amd64）

从同一个发布版本下载桌面包 `obituary_<版本>_linux_amd64.deb` 和 `checksums.txt`。在下载目录运行以下命令，把 `VERSION` 换成实际版本号，校验成功后再安装：

```bash
file=obituary_VERSION_linux_amd64.deb
grep -F "  $file" checksums.txt | sha256sum --check --strict - && sudo apt install "./$file"
```

从应用列表打开「讣告」。小窗口使用 GTK 3 和 WebKitGTK 4.1，依赖由 apt 安装。希望下次登录桌面时启动托盘，在设置页打开「随登录启动托盘」；关闭同一开关会移除讣告自己的 XDG 自启项。

托盘需要支持 StatusNotifierItem 的宿主。GNOME 没有宿主时，仍可从应用列表打开同一窗口，无需安装扩展。卸载时先关闭托盘自启并退出托盘，再运行 `sudo apt remove obituary-desktop`；墓地、设置、原有 CLI 和用户定时器都会保留。

## Windows 托盘

`obit init` 让托盘图标随登录启动，常驻在任务栏通知区。菜单顶上一行写着 24 小时内要下葬几项、墓地里有几座（暂停时写「已暂停」）。菜单里有：

- 最近下葬的（点一条就复活，系统通知会说放回了哪里）；
- 24 小时内要到期的；
- 暂停 / 继续自动清理；
- 打开讣告（小窗口；`obit-gui.exe` 不在 `obitd.exe` 旁边时，弹通知说明）；
- 退出（定时任务仍在兜底）。

## 小窗口

`obit-gui.exe` 有五页：即将下葬、即将火化（墓地）、待你决定、设置、日志。开始菜单、桌面上的「讣告」和托盘菜单「打开讣告」都能打开它。

- 首页顶栏写着「自动登记：关」或「自动登记：开」，点一下到设置。「待你决定」最上面和设置页都能切换：关（默认，只有 agent 和你自己登记的进讣告）、分级、全自动、全部都问，见[什么进讣告](./auto-register)。没问你就进了讣告的东西列在页面下方「已自动处理」，每一项都能一键撤回（不再计时，东西留在原处）或续命。
- 到期却没埋成的（比如文件被别的程序占着），列在「待你决定」的「没埋成的」里：写着原因和下次重试的时间。讣告隔一阵再试，间隔越来越长，多次失败后停下等你：「重试」现在再埋一次，「不再跟踪」让它留在原处。
- Docker 没启动时，容器提议的「批准」不可用，卡片上直说原因；启动 Docker 后再批准。
- 复活一项后，提示条上有「打开所在文件夹」，资源管理器会打开它所在的文件夹并选中它。
- 信任 `.obitrules` 时只信任你在窗口里看到的那一版内容。
- 界面有中文和英文；窗口、托盘和右键菜单的语言跟着 `config.toml` 的 `[ui] language`（`auto`、`zh-CN` 或 `en`；`auto` 跟随 Windows），也可以在「设置」里换。
- 需要 WebView2 运行时（Windows 11 自带，Windows 10 多数已经装好），目前只有 x64 版。

### 更新

有正式新版时，从「设置 → 关于与更新」安装。讣告会关闭窗口和正在运行的托盘，用原来的 Scoop、WinGet 或安装脚本渠道升级，再尝试恢复托盘、重新打开窗口。失败原因和日志路径也在这里显示。

自己解压的版本也能原地更新，按钮写着「下载并重启更新」。讣告先从 GitHub 下载发布包（GitHub 十秒内没有响应就改用国内镜像），核对 SHA-256 无误后才关闭窗口，只替换这个文件夹里讣告自己的程序（`obit`、`obitd`、`obit-gui`），其他文件一概不动，也不改 PATH 和开始菜单。旧程序留在同一位置的隐藏文件夹 `.obituary-update-…` 里，一天后进墓地，仍可复活；任何一步失败（包括新的 `obit` 起不来）都会把旧版本放回去。条件是：运行的是正式发布版（不是开发版或本地构建）、文件夹里有发布包里讣告自己的全部程序且都是普通文件、当前用户不需要管理员权限就能写入这个文件夹；哪一条不满足，页面会写明，仍可到发布页下载替换。终端里用 `obit update --apply`。「这一版改了什么」只显示窗口所用语言的那一段，没有对应语言就显示英文。

### 八种外观

在「设置 → 外观」里换，只改这台电脑上窗口的样子，点了立即换。

| 外观 | 样子 |
|---|---|
| 日历 | 每一列是一天，文件排在它下葬或火化的那天；拖到后面某天就延长到那天。 |
| 一行 | 一行输入，键盘直达：搜文件，回车复活或延长。 |
| 隧道 | 3D 时间隧道，越近越快到期，滚轮在时间里穿行。 |
| 长明 | 深色，每个文件一盏灯，灯越暗越快到期。 |
| 讣闻 | 报纸讣闻版：宋体分栏，复活时盖章。 |
| 地平线 | 地上是在跟踪的文件，地下是墓地。 |
| 云母 | Windows 11 原生质感，左侧导航。 |
| 夜航 | 安静的深色，顶部导航。 |

## 右键菜单

`obit init` 默认装好资源管理器右键菜单（只写当前用户的注册表）。右键文件或文件夹，选「放进讣告」，再选：

- **1 天 / 7 天 / 30 天**：到期下葬，期间文件照常用；
- **现在埋掉（可恢复）**：马上进墓地，保留期内（默认 7 天）都能复活。

![资源管理器右键菜单：现在埋掉（可恢复）、放进讣告（1 天、7 天、30 天）、复活最近下葬的](/context-menu-zh.png)

可以一次选中很多个文件一起放。做完弹一条通知：放进了几项、多久后下葬、失败几项。Windows 11 的新菜单里没有它，点「显示更多选项」（或按住 Shift 再右键）就能看到。`obit init --dry-run` 会列出每一项菜单名和命令，`obit doctor` 检查它装得对不对。

macOS 和 Linux 还没有右键菜单，先用命令：`obit mark <路径> 7d` 放进讣告，`obit bury <路径>` 现在埋掉。

## 图标和菜单

`obit init` 默认装好这些，设置页「图标和菜单」里每一项都有开关：

| 开关 | 管什么 |
|---|---|
| 托盘图标 | 任务栏通知区里的讣告；隐藏后后台照常清理 |
| 任务栏图标 | 小窗口打开时是否占一个任务栏位置 |
| 开始菜单 | 开始菜单里的「讣告」 |
| 桌面快捷方式 | 桌面上的「讣告」 |
| 右键菜单 | 资源管理器里的「放进讣告」菜单 |

安装时就不想要：`obit init --no-context-menu` 不装右键菜单，`--no-shortcuts` 不建开始菜单和桌面快捷方式。

资源管理器里显示下葬日期的做法见[文件夹策略](./folder-policies#资源管理器里的日期)。
