# ウィンドウ、トレイ、右クリックメニュー

コマンドラインを使わずに、ファイルの復活、提案の承認、設定の変更ができます。

## macOS の小窓とメニューバーアイコン

同じリリースから universal macOS DMG と checksums.txt をダウンロードします。SHA-256 を確認して DMG を開き、Obituary.app を「アプリケーション」またはユーザーの Applications フォルダーへドラッグします。ログイン起動を有効にする前に DMG を取り出してください。

app には Wails の小窓、メニューバーアイコン、対応する obit と obitd が入っています。5 分ごとに動く launchd ユーザーエージェントは別のフォールバックです。設定で「ログイン時にトレイを起動」を有効にすると、Obituary 専用の LaunchAgent を登録できます。無効にするとその項目だけを削除します。

`Obituary.app` を削除しても、デフォルトでは `~/Library/Application Support/obituary/` にデータが残ります。`store.json` は台帳、`config.toml` は設定ファイルで、このボリュームで埋葬したファイルは `graveyard/` に残ります。

### 未署名 app を初めて開くとき

このリリースには Developer ID 署名も公証もありません。信頼できるリリースから取得したことと SHA-256 を確認して、一度開いてみます。macOS が開発元を確認できないと表示したら、「システム設定 → プライバシーとセキュリティ」で Obituary の「このまま開く」を選び、確認後にもう一度開きます。Gatekeeper を全体で無効にしたり、隔離属性を再帰的に消したりしないでください。破損、マルウェア、または会社のポリシーによる拒否が表示されたら停止します。

### Homebrew Cask の案

Cask は同じ universal DMG を使い、Obituary.app を「アプリケーション」にコピーし、app bundle の obit と obitd を利用可能にします。デスクトップ DMG の安定した公開 URL とアンインストール確認が整うまでは、既存の CLI 用 cask と分けます。
## トレイ

`obit init` を実行すると、ログイン時にトレイアイコンが表示されます。メニューから次の操作ができます。

- 最近埋葬した項目を表示し、クリックして復活する。
- 24 時間以内に期限が切れる項目を確認する。
- 自動クリーンアップを一時停止・再開する。
- 「Open Obituary」で小ウィンドウを開く。`obit-gui.exe` が `obitd.exe` と同じディレクトリにないときは、通知で理由を知らせます。
- トレイを終了する。スケジュールされたタスクは引き続き動作します。

## 小窓

`obit-gui.exe` には Upcoming、Graveyard、Decisions、Settings、Logs の 5 ページがあります。スタートメニューの「Obituary」、デスクトップのショートカット、トレイの「Open Obituary」から開けます。

- ホーム上部の「Auto registration: off」または「on」をクリックすると設定が開きます。Decisions の上部または Settings で、無効（既定。ユーザーとエージェントが登録したものだけ）、段階的、全自動、すべて確認の 4 モードを切り替えられます。[登録の対象](./auto-register)を参照してください。確認なしで登録された項目は下の「Handled automatically」に並びます。各項目はワンクリックで登録を取り消して元の場所に残すか、寿命を延長できます。取り消すとカウントダウンは止まります。
- 期限が切れても埋葬できなかった項目（他のプログラムが開いているファイルなど）は、Decisions の「Burials that failed」に理由と次回の試行時刻が表示されます。再試行の間隔は徐々に長くなり、失敗が続くとユーザーの判断を待ちます。「Retry」は今すぐ再試行、「Stop tracking」は追跡をやめて項目を元の場所に残します。
- Docker の停止中はコンテナの提案を承認できず、カードに理由が表示されます。Docker を起動してから承認してください。
- `.obitrules` を信頼した場合、その時点でウィンドウに表示されている版だけが対象です。
- ウィンドウ、トレイ、コンテキストメニューの言語は `config.toml` の `[ui] language` で設定します（`auto`、`zh-CN`、`en`。`auto` は Windows に従います）。設定画面でも切り替えられます。
- 小ウィンドウは x64 専用で、WebView2 ランタイムが必要です。Windows 11 には標準搭載され、ほとんどの Windows 10 端末にも入っています。

### 更新

「Settings → About and updates」から新しい安定版をインストールできます。Obituary はウィンドウとトレイを閉じ、元のインストール方法（Scoop、WinGet、スクリプト）で更新し、トレイとウィンドウの再起動を試みます。失敗した場合は同じページにエラーとログのパスが表示されます。

自分で展開したコピーもその場で更新できます。ボタンには「Download and restart to update」と表示されます。Obituary は GitHub からリリースをダウンロードし（GitHub が 10 秒以内に応答しない場合は中国本土のミラーを使用）、SHA-256 を検証してから、ウィンドウを閉じてそのフォルダー内の Obituary 自身のプログラム（`obit`、`obitd`、`obit-gui`）だけを置き換えます。フォルダー内の他のファイルには触れず、PATH やスタートメニューも変更しません。以前のプログラムは同じ場所の隠しフォルダー `.obituary-update-…` に 1 日残り、その後は墓地に移され、復活もできます。新しい `obit` が起動しない場合を含め、どの手順で失敗しても以前のバージョンに戻します。条件は、安定版であること（開発ビルドではない）、リリースのプログラムがすべて通常のファイルとしてフォルダーにあること、管理者権限なしで現在のユーザーがフォルダーに書き込めることです。満たさない条件があれば画面に示されるので、リリースページから新しい版をダウンロードして置き換えてください。ターミナルでは `obit update --apply` で同じことができます。「What changed」はウィンドウの言語で表示され、対応する言語がなければ英語になります。

### 8 種類の外観

「Settings → Appearance」で切り替えると、このコンピューターのウィンドウだけにすぐ反映されます。

| 外観 | 特徴 |
|---|---|
| カレンダー | 1 列が 1 日で、ファイルが埋葬または永久削除の日に並びます。後の日へドラッグすると寿命を延長できます。 |
| 1 行 | キーボードだけで操作できる入力欄です。ファイルを探し、Enter で復活または延長します。 |
| トンネル | 時間を 3D のトンネルで表します。手前ほど期限が近く、スクロールで時間を移動できます。 |
| Vigil | 暗い画面で各ファイルを灯りで表します。暗い灯りほど期限が近いことを示します。 |
| Notices | セリフ体の段組みを使った新聞の訃報欄。復活するとスタンプが押されます。 |
| 地平線 | 追跡中のファイルは地上に、墓地は地下に表示されます。 |
| Mica | サイドバー付きの Windows 11 標準風の外観です。 |
| ナイト | 上部バーを備えた静かな暗いテーマ。 |

## コンテキストメニュー

`obit init` は既定で、現在のユーザーにだけエクスプローラーのコンテキストメニューを追加します。ファイルやフォルダーを右クリックし、「Add to Obituary」から選んでください。

- **1 日／7 日／30 日**：指定した期間が過ぎたら埋葬します。それまでは普通に使えます。
- **Bury now (recoverable)**：すぐに墓地へ移し、保持期間（既定は 7 日）中は復活できます。

複数のファイルを選んで一度に追加できます。通知には登録件数、埋葬予定、失敗件数が表示されます。Windows 11 の新しいメニューには表示されないため、「その他のオプションを確認」を選ぶか、Shift を押しながら右クリックします。`obit init --dry-run` は各項目とコマンドを一覧表示し、`obit doctor` は正しくインストールされているか確認します。

macOS と Linux にはまだコンテキストメニューがありません。登録には `obit mark <path> 7d`、すぐに埋葬するには `obit bury <path>` を使ってください。

## アイコンとメニュー

`obit init` で次の項目が既定で設定されます。それぞれ「Settings → Icons and menus」で切り替えられます。

| スイッチ | 内容 |
|---|---|
| トレイアイコン | 通知領域の Obituary アイコン。非表示にしてもクリーンアップは続きます。 |
| タスクバーアイコン | ウィンドウを開いている間、タスクバーに表示するかどうか。 |
| スタートメニュー | スタートの「Obituary」 |
| デスクトップショートカット | デスクトップに Obituary を表示 |
| コンテキストメニュー | エクスプローラーの「Add to Obituary」メニュー。 |

インストール時に `obit init --no-context-menu` を指定するとコンテキストメニューを、`--no-shortcuts` を指定するとスタートメニューとデスクトップのショートカットを作成しません。

エクスプローラーに表示する埋葬日については、[フォルダーポリシー](./folder-policies#dates-in-explorer)を参照してください。
