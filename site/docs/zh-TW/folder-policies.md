# 資料夾策略

資料夾策略會為每個放進資料夾的項目分別設定壽命。常見的例子是「下載」資料夾：

```powershell
obit watch C:\Users\你\Downloads 2w          # 放进来的每样东西两周后进墓地
obit watch --list                           # 有哪些文件夹策略，各自的豁免和安静期
obit watch --remove C:\Users\你\Downloads    # 移除策略，它登记过的寿命一起取消
```

## 策略如何生效

- **策略須經你核准。** `obit watch` 會建立一項提議。執行 `obit approve` 或在小視窗的「待你決定」頁核准後，策略才會生效。
- **檔案須連續 10 分鐘沒有變動。** 只有當壽命已到期，且檔案已有 10 分鐘未被改動時，才會下葬。
- **子資料夾另行提議。** 子資料夾到期時，訃告只會提出建議，等你核准後才下葬。
- 移除策略時，它登記過的壽命一起取消。

## 檔案總管中的日期 {#explorer-dates}

在「下載」、桌面和套用策略的資料夾中，檔案總管會將追蹤中的項目顯示為「名稱（11-13 下葬）」，實際檔名不變。

- 日期來自資料夾中的隱藏檔 `desktop.ini`。
- 在 `config.toml` 的 `[explorer]` 區段中，可設定 `enabled = false` 關閉日期顯示，或設定 `everywhere = true` 在所有位置顯示。
- 檔案總管會快取資料夾的檢視畫面。延長壽命後，同一個視窗最多可能還會顯示舊日期一分鐘。
