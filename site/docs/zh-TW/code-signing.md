# 程式碼簽署政策

[SignPath.io](https://about.signpath.io/) 提供免費的程式碼簽署服務，憑證由 [SignPath Foundation](https://signpath.org/) 提供。

## 簽署範圍

- 發行版壓縮檔中的 `obit.exe`、`obitd.exe` 和 `obit-gui.exe`。
- GitHub Actions 的發行流程（[`release.yml`](https://github.com/woodfishhhh/obituary/blob/main/.github/workflows/release.yml)）只會從本儲存庫中帶有標籤的提交自動建置這些程式。建置指令稿和 CI 設定也都放在儲存庫中。
- 每項簽署要求都須由下表所列的核准人員手動核准。
- 在檔案的「內容」→「詳細資料」中可以看到產品名稱「Obituary 讣告」和版本。

## 團隊和角色

| 角色 | 成員 |
| --- | --- |
| 提交者與審查者 | [woodfishhhh](https://github.com/woodfishhhh) |
| 簽署核准人員 | [woodfishhhh](https://github.com/woodfishhhh) |

團隊以外的人提交的變更，都要先由維護者審查才能合併。所有成員都在 GitHub 上使用多因素驗證。

## 隱私

使用統計和自動檢查更新可以分別關閉。詳見[隱私政策](privacy)。
