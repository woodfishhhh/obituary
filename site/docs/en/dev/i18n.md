# Internationalization

CLI and tray messages live in `internal/i18n`. Define a stable ID and English default in `messages.go`, then update the catalogs and check their placeholders. Language selection respects explicit overrides, configuration and the environment. Traditional Chinese tags must not select Simplified Chinese. Keep MCP names, JSON fields, exit codes, commands, log markers and host protocol output unchanged.

Website languages are listed in `site/landing/src/locales.ts`. Landing copy must match the shape of the Simplified Chinese copy. User manuals and agent guides have ten locale trees; the developer guide has two. Navigation in the remaining languages points to the English developer guide instead of duplicating English content.

The root `README.md` is the English source. Diagram strings live in `docs/assets/readme/i18n/strings.json`; regenerate both light and dark variants after editing and follow `docs/README.md` to check layout, links and image paths. Both [website builds](./build-test) check translated pages, generated guides and language alternates.
