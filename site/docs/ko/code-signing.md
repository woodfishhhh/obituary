# 코드 서명 정책

[SignPath.io](https://about.signpath.io/)는 코드 서명 서비스를 무료로 제공하고 [SignPath Foundation](https://signpath.org/)은 인증서를 발급합니다.

## 서명 대상

- 릴리스 압축 파일에 포함된 `obit.exe`, `obitd.exe`, `obit-gui.exe`입니다.
- GitHub Actions의 릴리스 워크플로([`release.yml`](https://github.com/woodfishhhh/obituary/blob/main/.github/workflows/release.yml))는 이 저장소에서 태그가 붙은 커밋만 사용해 프로그램을 자동으로 빌드합니다. 빌드 스크립트와 CI 설정도 같은 저장소에 있습니다.
- 아래 표에 있는 승인자가 서명 요청을 건별로 직접 승인합니다.
- 파일 속성의 ‘자세히’ 탭에서 제품 이름 ‘Obituary 讣告’와 버전을 확인할 수 있습니다.
