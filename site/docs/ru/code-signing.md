# Политика подписи кода

[SignPath.io](https://about.signpath.io/) бесплатно предоставляет сервис подписи кода, а [SignPath Foundation](https://signpath.org/) выдаёт сертификат.

## Какие файлы подписываются

- Файлы `obit.exe`, `obitd.exe` и `obit-gui.exe` из архивов релиза.
- Процесс выпуска в GitHub Actions ([`release.yml`](https://github.com/woodfishhhh/obituary/blob/main/.github/workflows/release.yml)) автоматически собирает программы только из коммитов этого репозитория, отмеченных тегом. Скрипты сборки и настройки CI находятся в том же репозитории.
- Каждый запрос на подпись вручную одобряет один из ответственных, указанных ниже.
- В свойствах файла на вкладке «Подробно» указаны название продукта «Obituary 讣告» и версия.

## Роли в команде

| Роль | Участники |
| --- | --- |
| Внесение и проверка изменений | [woodfishhhh](https://github.com/woodfishhhh) |
| Одобрение запросов на подпись | [woodfishhhh](https://github.com/woodfishhhh) |

Перед слиянием сопровождающий проверяет каждое изменение от участника, не входящего в команду. Все члены команды используют многофакторную аутентификацию на GitHub.

## Конфиденциальность

Статистику использования и автоматическую проверку обновлений можно отключать независимо друг от друга. Подробности см. в [политике конфиденциальности](privacy).
