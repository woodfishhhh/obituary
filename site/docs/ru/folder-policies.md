# Правила для папок

Правило задаёт отдельный срок жизни каждому элементу, который попадает в папку. Часто такое правило нужно для папки «Загрузки»:

```powershell
obit watch C:\Users\you\Downloads 2w        # files that land in Downloads are buried two weeks later
obit watch --list                           # folder policies, their exemptions and quiet periods
obit watch --remove C:\Users\you\Downloads  # remove a policy and the lifespans it registered
```

В macOS и Linux после одобрения политики у каждого элемента верхнего уровня свой срок, по умолчанию с момента первого обнаружения. Сама папка защищена; для просроченных подпапок создаются только предложения, временные файлы загрузок пропускаются.

По умолчанию после истечения срока обычный файл должен оставаться без изменений ещё десять минут. Если меняется размер или время изменения или файл открыт, отсчёт начинается заново. Windows блокирует запись на время перемещения. В macOS и Linux процесс может открыть файл между проверкой и переименованием.

В автоматическом режиме должны быть доступны для проверки все процессы владельца файла. Недоступные процессы других пользователей, включая root, можно пропустить лишь для собственного файла, если у группы и остальных нет права записи. Выберите `propose` для пофайлового подтверждения. Подтверждение допускает неполные сведения о процессах. Если файл заведомо открыт, он останется на месте с указанием причины.

Для отдельного подтверждения укажите `file_expiry = "propose"` в разделе `[watch]`. Просмотрите предложения командой `obit proposals` и подтвердите нужное командой `obit approve <ID>`. Для просроченных подпапок по-прежнему создаются предложения, а в macOS и Linux подпапки остаются на месте даже после подтверждения.

```sh
obit watch "$HOME/Downloads" 2w
```

## Когда действует правило

- **Само правило нужно одобрить.** `obit watch` создаёт предложение. Правило начнёт действовать после того, как вы выполните `obit approve` или одобрите предложение на странице «Для вас» в небольшом окне программы.
- **Файл не должен меняться десять минут.** Его похоронят, только когда срок жизни истёк и последние десять минут файл не изменялся.
- **Для вложенных папок создаются отдельные предложения.** Когда срок жизни папки истекает, появляется только предложение. Папку похоронят после вашего одобрения.
- Если убрать правило, все зарегистрированные им сроки жизни отменяются.

## Даты в Проводнике {#dates-in-explorer}

В «Загрузках», на рабочем столе и в папках с правилами Проводник показывает отслеживаемые элементы в виде «name (11-13 burial)». Настоящее имя файла не меняется. Подпись зависит от языка интерфейса Obituary: для упрощённого китайского она выглядит как «name（11-13 下葬）», а в остальных случаях остаётся английской.

- Даты берутся из скрытого файла `desktop.ini` в соответствующей папке.
- В разделе `[explorer]` файла `config.toml` можно отключить показ дат (`enabled = false`) или включить его во всех папках (`everywhere = true`).
- Проводник кеширует представления папок. После продления срока жизни в том же окне до минуты может отображаться старая дата.

Finder и Dolphin показывают дату захоронения в метке, не меняя имя файла. При продлении срока дата обновляется. При отмене отслеживания или удалении программы исчезают только метки Obituary. В Nautilus дату можно посмотреть с помощью `obit list`.
