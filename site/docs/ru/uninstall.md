# Удаление программы

```powershell
obit uninstall --dry-run      # see what would be removed
obit uninstall                # remove everything Obituary set up, after you confirm
.\install.ps1 -Uninstall      # if you used the install script: also remove the program files, PATH entry and Start menu shortcut
```

`obit uninstall` удаляет только то, что добавила сама Obituary: хуки агентов, MCP и Skill для пользователя и текущего Git-проекта, автозапуск при входе, задание планировщика, работающий фоновый процесс, контекстное меню, метки дат в Проводнике и правила для папок.

## Кладбище и реестр сохраняются

По умолчанию кладбище и реестр сохраняются. Команда сообщает, где находится кладбище и сколько в нём хранится. Чтобы удалить и то и другое, добавьте `--purge-data`: сначала программа покажет содержимое кладбища, затем ещё раз запросит подтверждение.

## Хуки в других проектах

Если в других проектах тоже установлены локальные хуки, выполните `obit uninstall` в каждом из них, прежде чем удалять программу. Иначе после удаления `obit` эти хуки перестанут работать.

## Scoop и winget

Сначала выполните `obit uninstall`, затем команду удаления того менеджера пакетов, через который устанавливали программу.
