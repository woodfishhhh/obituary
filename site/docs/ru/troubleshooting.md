# Устранение неполадок

Начните с `obit doctor`. Он проверяет установку, интеграции, фоновые службы и данные без изменения файлов. Для подробностей добавьте `--json` или `--verbose`.

## PATH и контрольные суммы

**Симптом:** shell не находит `obit` или контрольная сумма архива не совпадает.

**Решение:** скачайте `checksums.txt` из того же выпуска и выполните `sha256sum --check --strict checksums.txt`. В PowerShell сравните с `Get-FileHash .\obit-*.zip -Algorithm SHA256`. Несовпадающий файл не запускайте; после изменения PATH откройте новый терминал.

## Графический интерфейс

В Windows сначала проверьте SHA-256, затем в SmartScreen выберите «Подробнее → Выполнить в любом случае». При отсутствии WebView2 установите Microsoft Edge WebView2 Runtime. Окно Windows сейчас доступно только для x64.

Приложение macOS не подписано Developer ID и не прошло нотариальную проверку. Проверьте сумму и разрешите первый запуск в «Системные настройки → Конфиденциальность и безопасность → Открыть в любом случае». Не отключайте Gatekeeper и не разрешайте приложение с предупреждением о повреждении или вредоносном ПО. Для LaunchAgent проверьте `obit daemon status` и `launchctl list | grep obituary`.

Окну Ubuntu 24.04 нужны GTK 3 и WebKitGTK 4.1:

```bash
sudo apt update
sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0
obit doctor
```

Планировщик проверяется командами `systemctl --user status obituary.timer`, `systemctl --user list-timers | grep obituary` и `crontab -l`.

## Фоновые задачи, обновления и файлы

Используйте `obit daemon status`, `obit sweep` для немедленной проверки и `obit daemon enable` для включения расписания. Для китайского зеркала используется `bash install.sh --mirror cn`; не смешивайте архивы и суммы разных выпусков.

После переименования диска WSL подтвердите настоящий путь Windows. Занятые файлы остаются на месте и проверяются повторно. Ошибки TOML показываются с файлом и строкой командой `obit config`.

## Интеграции и контейнеры

Если hook не работает, выполните `obit init --show`, `obit init --dry-run`, `obit doctor --verbose` и проверьте, что `OBIT_DISABLED=1` не задан. Аудит доступен через `OBIT_HOOK_AUDIT=1 obit hook audit`. Запустите Docker перед подтверждением контейнера. Восстановление не перезаписывает существующую цель, а использует имя без конфликта.
