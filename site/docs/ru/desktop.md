# Окно, область уведомлений и контекстное меню

Восстанавливать файлы, одобрять предложения и менять настройки можно без командной строки.

## Что есть на каждой из трёх платформ

Окно, значок в области уведомлений и уведомления рабочего стола есть в Windows, macOS и Ubuntu 24.04. Настольные версии для macOS и Ubuntu пока предварительные. У других дистрибутивов Linux настольной версии нет, там используется командная строка.

| | Windows | macOS | Ubuntu 24.04 |
| --- | --- | --- | --- |
| Окно | `obit-gui.exe`, только x64 | `Obituary.app`, универсальное для Intel и Apple Silicon | пакет `.deb`, только amd64 |
| Значок | область уведомлений | строка меню | значок в области уведомлений; нужен рабочий стол с поддержкой StatusNotifierItem |
| Значок при входе | включён по умолчанию после `obit init` | переключатель в Settings | переключатель в Settings |
| Проверка истечения сроков | постоянный процесс значка | LaunchAgent | systemd |
| Уведомления рабочего стола | есть | есть | есть |
| Контекстное меню | в Проводнике | Finder: Быстрые действия | Nautilus: Сценарии · Dolphin |
| Метки с датой | есть | Finder | Dolphin |
| Режим Корзины | есть | нет, только кладбище | есть |
| Устанавливается через | скрипт установки, Scoop, winget или архив | DMG | `.deb` |
| Первый запуск | у архива, скачанного вручную, может появиться предупреждение SmartScreen | нужно вручную разрешить, см. [ниже](#первыи-запуск-неподписанного-app) | открывается сразу |
| Требования | WebView2 Runtime | 1.6.0 требует macOS 26 (исправлено в 1.6.1) | GTK 3 и WebKitGTK 4.1, их ставит apt |

В Windows процессом управляет задание при входе в систему, в macOS — пользовательский LaunchAgent, а в графическом сеансе Linux — пользовательская служба systemd. После сбоя процесс перезапускается через 60 секунд; после третьего сбоя за 15 минут попытки прекращаются.

Когда в настольной версии включён надзор, процесс в трее обрабатывает записи по истечении срока, а отдельное задание проверяет их раз в час. Если для этого каталога данных надзор за процессом в трее не включён, задание запускается каждые пять минут.

В Windows старое задание переносится только при совпадении с определением, созданным Obituary для этой установки. Исходное определение сохраняется для отката; изменённые и отключённые задания остаются как есть.

## Малое окно и значок в строке меню macOS

Скачайте универсальный DMG (`obituary_<версия>_darwin_universal.dmg`) и `checksums.txt` со страницы выпуска, проверьте SHA-256, откройте DMG, перетащите Obituary.app в «Программы», извлеките DMG и откройте приложение из «Программ». Перетащить его нужно заранее, потому что запись автозапуска при входе хранит место, где лежит приложение, а приложение, запущенное прямо из DMG, после извлечения образа там уже не находится.

В приложении есть окно, значок в строке меню и сопутствующие программы `obit` и `obitd`. Если включить «Start the tray at sign-in» в Settings окна, будет установлен собственный пользовательский LaunchAgent Obituary, чтобы значок в строке меню появлялся при входе; если выключить, удалится только эта запись.

Для установки независимого задания проверки выполните `obit daemon enable`. Закрытие окна или выход через значок в строке меню не отключает это задание.

После удаления `Obituary.app` данные по умолчанию остаются в `~/Library/Application Support/obituary/`: `store.json` содержит реестр, `config.toml` — настройки, а `graveyard/` — файлы, похороненные на этом томе.

### Первый запуск неподписанного app

У выпуска нет подписи Developer ID, и он не нотаризован, поэтому при первом запуске macOS его останавливает. Убедившись, что загрузка пришла с надёжной страницы выпуска, и проверив SHA-256, откройте приложение один раз обычным способом. Если система пишет, что не может проверить разработчика, откройте «Системные настройки», затем «Конфиденциальность и безопасность», найдите Obituary внизу страницы, выберите «Всё равно открыть», подтвердите ещё раз и откройте приложение снова. Не отключайте для этого Gatekeeper глобально и не стирайте атрибут карантина рекурсивно. Если система сообщает, что приложение повреждено или содержит вредоносное ПО либо что политика организации запрещает его открывать, остановитесь на этом.

### 1.6.0 требует macOS 26

Окну для macOS в версии 1.6.0 нужна macOS 26. В macOS 15 и более ранних система сообщает, что приложение несовместимо с этой версией, и оно не открывается. В 1.6.1 это исправлено.

## Ubuntu 24.04 (amd64)

Скачайте настольный пакет `obituary_<версия>_linux_amd64.deb` и `checksums.txt` со страницы выпуска. В каталоге загрузки выполните команды ниже, заменив `VERSION` на скачанную версию; пакет устанавливается, только если проверка прошла успешно:

```bash
file=obituary_VERSION_linux_amd64.deb
grep -F "  $file" checksums.txt | sha256sum --check --strict - && sudo apt install "./$file"
```

После этого откройте Obituary из списка приложений. Окно использует GTK 3 и WebKitGTK 4.1, и apt устанавливает их вместе с пакетом. Программы лежат в `/usr/libexec/obituary/`, а этой папки нет в вашем PATH; чтобы пользоваться `obit` в терминале, установите командную строку отдельно скриптом установки.

Значку в области уведомлений нужен рабочий стол с поддержкой StatusNotifierItem, а GNOME по умолчанию её не предоставляет. Там то же окно открывается из списка приложений без каких-либо расширений, но значка нет. Чтобы значок появился при следующем входе, включите «Start the tray at sign-in» в Settings; если выключить, запись автозапуска, созданная Obituary, будет удалена. О деинсталляции см. [Удаление программы](./uninstall).

## Значок в области уведомлений

После `obit init` при входе в систему появляется значок в области уведомлений. В его меню доступны:

- недавно похороненные объекты: щёлкните объект, чтобы его воскресить;
- объекты, срок жизни которых истекает в ближайшие 24 часа;
- приостановка и возобновление автоматической очистки;
- «Open Obituary»: открывает небольшое окно. Если `obit-gui.exe` нет в каталоге с `obitd.exe`, появится уведомление с объяснением;
- выход из программы в области уведомлений (задание планировщика продолжит работу).

## Малое окно

В `obit-gui.exe` пять страниц: Expiring, Graveyard, For you, Settings и Logs. Открыть окно можно из меню «Пуск» через «Obituary», ярлыком на рабочем столе или пунктом «Open Obituary» в области уведомлений.

- Верхняя строка главной страницы показывает «Auto registration: off» или «on». Щелчок открывает настройки. Режим можно сменить вверху страницы For you или в Settings: выключено (по умолчанию, регистрируете только вы и агент), многоуровневый режим, полностью автоматический или всегда спрашивать. См. [что попадает в реестр](./auto-register). Ниже, в «Handled automatically», показаны записи, добавленные без запроса. Одним щелчком можно отменить регистрацию (отсчёт остановится, объект останется на месте) или продлить срок жизни.
- Если срок истёк, но похоронить объект не удалось, например файл ещё открыт другой программой, он появится в «Burials that failed» на странице For you. Там указаны причина и время следующей попытки. Интервалы между попытками растут. После нескольких неудач Obituary ждёт вашего решения: «Retry» повторяет попытку немедленно, «Stop tracking» прекращает отслеживание и оставляет объект на месте.
- Пока Docker не запущен, кнопка одобрения предложения по контейнеру недоступна. Причина указана на карточке. Одобрить предложение можно после запуска Docker.
- Доверие к файлу `.obitrules` распространяется только на ту версию, которую вы видите в окне.
- Язык окна, значка в области уведомлений и контекстного меню задаёт `[ui] language` в `config.toml` (`auto`, `zh-CN` или `en`; `auto` выбирает язык Windows). Его можно сменить и в настройках.
- Окно доступно только для x64 и требует среды выполнения WebView2. Она входит в Windows 11 и установлена на большинстве компьютеров с Windows 10.

### Обновления

Более новую стабильную версию можно установить в Settings → About and updates. Obituary закрывает окно и программу в области уведомлений, обновляется через исходный канал установки (Scoop, WinGet или скрипт), затем пытается вернуть значок и снова открыть окно. Причины неудач и пути к журналам показаны на той же странице.

Копия, которую вы распаковали вручную, тоже обновляется на месте; на кнопке написано «Download and restart to update». Obituary скачивает выпуск с GitHub (с зеркала в материковом Китае, если GitHub не отвечает в течение десяти секунд), проверяет SHA-256 и только после этого закрывает окно и заменяет в этой папке собственные программы Obituary (`obit`, `obitd` и `obit-gui`). Остальные файлы папки остаются как есть, PATH и меню «Пуск» не затрагиваются. Прежние программы сутки лежат в скрытой папке `.obituary-update-…` на том же месте, затем переходят на кладбище, откуда их ещё можно воскресить; если любой шаг не удался, в том числе новый `obit` не запускается, возвращается прежняя версия. Нужны стабильный выпуск (не сборка для разработки), все программы выпуска в папке как обычные файлы и папка, в которую текущий пользователь может писать без прав администратора. Если какое-то условие не выполнено, страница назовёт его, а новую копию можно скачать со страницы выпусков. В терминале то же делает `obit update --apply`. «What changed» показывает заметки на языке окна, а если перевода нет — на английском.

### Восемь вариантов оформления

Выберите оформление в Settings → Appearance. Оно меняется сразу и только для окна на этом компьютере.

| Оформление | Описание |
|---|---|
| Календарь | Один столбец на день. Файл отображается в день захоронения или безвозвратного удаления. Перетащите файл на более позднюю дату, чтобы продлить срок жизни. |
| Одна строка | Одна строка ввода, управление с клавиатуры: найдите файл и нажмите Enter, чтобы воскресить его или продлить срок. |
| Туннель | Трёхмерный туннель времени: чем ближе файл, тем скорее истечёт его срок. Прокручивайте, чтобы перемещаться по времени. |
| Бдение | На тёмном фоне каждому файлу соответствует лампа. Чем она тусклее, тем ближе истечение срока. |
| Некрологи | Газетная полоса некрологов: колонки со шрифтом с засечками, при воскрешении появляется штамп. |
| Горизонт | Отслеживаемые файлы над землёй, кладбище под ней. |
| Mica | Оформление в стиле Windows 11 с боковой панелью. |
| Ночь | Спокойная тёмная тема с верхней панелью. |

## Контекстное меню

`obit init` по умолчанию устанавливает контекстное меню Проводника только для текущего пользователя. Щёлкните файл или папку правой кнопкой, выберите «Add to Obituary», а затем один из вариантов:

- **1 день / 7 дней / 30 дней**: объект похоронят по истечении срока, а до этого им можно пользоваться как обычно.
- **Bury now (recoverable)**: объект немедленно перемещается на кладбище и доступен для воскрешения в течение срока хранения (по умолчанию 7 дней).

Можно выбрать и добавить сразу несколько файлов. Уведомление покажет, сколько объектов добавлено, когда их похоронят и сколько не удалось добавить. В новом меню Windows 11 этих команд нет: выберите «Показать дополнительные параметры» или удерживайте Shift при щелчке правой кнопкой. `obit init --dry-run` выводит все пункты и их команды; `obit doctor` проверяет установку.

Если после обновления все пункты меню Проводника отображаются на другом поддерживаемом языке, меню по-прежнему работает. `obit doctor` выдаёт информационное сообщение (в JSON: `installation: label-language-mismatch`). Выполните `obit init --context-menu --yes`, чтобы применить текущий язык интерфейса.

В Finder откройте «Быстрые действия», в Nautilus выберите «Сценарии → Obituary», а в Dolphin откройте подменю Obituary. Чтобы задать политику папки, сначала выделите её. В Dolphin вызов меню на пустом месте применяет действие к текущей папке. Чтобы захоронить файл, нажмите правой кнопкой на сам файл.

## Значки и меню

По умолчанию `obit init` настраивает все перечисленные элементы. Каждый можно отключить отдельно в Settings → Icons and menus:

| Переключатель | Что меняет |
|---|---|
| Значок в области уведомлений | Показывает значок Obituary. Если его скрыть, очистка продолжится. |
| Значок на панели задач | Занимает ли открытое окно место на панели задач. |
| Меню «Пуск» | Пункт «Obituary» в меню «Пуск». |
| Ярлык на рабочем столе | Ярлык «Obituary» на рабочем столе. |
| Контекстное меню | Пункт «Add to Obituary» в Проводнике. |

Если вы не хотите их уже при установке, добавьте `obit init --no-context-menu`, чтобы пропустить контекстное меню, или `--no-shortcuts`, чтобы пропустить ярлыки в меню «Пуск» и на рабочем столе. Те же параметры действуют и при удалении: `obit init --uninstall --no-shortcuts` оставляет существующие ярлыки и убирает всё остальное как обычно, а `--no-context-menu` так же поступает с контекстным меню.

О датах захоронения, которые показывает Проводник, см. [правила для папок](./folder-policies#dates-in-explorer).
