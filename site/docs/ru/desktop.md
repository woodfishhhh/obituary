# Окно, область уведомлений и контекстное меню

Восстанавливать файлы, одобрять предложения и менять настройки можно без командной строки.

## Малое окно и значок в строке меню macOS

Скачайте универсальный macOS DMG и файл checksums из одного выпуска. Проверьте SHA-256, откройте DMG и перетащите Obituary.app в «Программы» или пользовательскую папку Applications; извлеките DMG перед включением запуска при входе.

В app есть малое окно Wails, значок в строке меню и вспомогательные программы obit и obitd. Пользовательский агент launchd с проверкой каждые 5 минут остаётся отдельным резервным механизмом. В настройках включите запуск трея при входе, чтобы установить собственный LaunchAgent Obituary; отключение удаляет только эту запись.

После удаления `Obituary.app` данные по умолчанию остаются в `~/Library/Application Support/obituary/`: `store.json` содержит реестр, `config.toml` — настройки, а `graveyard/` — файлы, похороненные на этом томе.

### Первый запуск неподписанного app

Выпуск не имеет подписи Developer ID и нотариальной проверки. Убедитесь в источнике и SHA-256, затем один раз попробуйте открыть app. Если macOS не может проверить разработчика, откройте «Системные настройки → Конфиденциальность и безопасность», выберите для Obituary «Всё равно открыть», подтвердите и повторите запуск. Не отключайте Gatekeeper полностью и не удаляйте карантин рекурсивно. При сообщении о повреждении, вредоносном ПО или запрете политики организации остановитесь.

### Предложение для Homebrew Cask

Cask должен устанавливать тот же универсальный DMG, копировать Obituary.app в «Программы» и предоставлять obit и obitd из app bundle. Пока для desktop DMG нет стабильного URL и проверенного отчёта об удалении, его следует держать отдельно от существующего CLI cask.
## Значок в области уведомлений

После `obit init` при входе в систему появляется значок в области уведомлений. В его меню доступны:

- недавно похороненные объекты: щёлкните объект, чтобы его воскресить;
- объекты, срок жизни которых истекает в ближайшие 24 часа;
- приостановка и возобновление автоматической очистки;
- «Open Obituary»: открывает небольшое окно. Если `obit-gui.exe` нет в каталоге с `obitd.exe`, появится уведомление с объяснением;
- выход из программы в области уведомлений (задание планировщика продолжит работу).

## Малое окно

В `obit-gui.exe` пять страниц: Upcoming, Graveyard, Decisions, Settings и Logs. Открыть окно можно из меню «Пуск» через «Obituary», ярлыком на рабочем столе или пунктом «Open Obituary» в области уведомлений.

- Верхняя строка главной страницы показывает «Auto registration: off» или «on». Щелчок открывает настройки. Режим можно сменить вверху страницы Decisions или в Settings: выключено (по умолчанию, регистрируете только вы и агент), многоуровневый режим, полностью автоматический или всегда спрашивать. См. [что попадает в реестр](./auto-register). Ниже, в «Handled automatically», показаны записи, добавленные без запроса. Одним щелчком можно отменить регистрацию (отсчёт остановится, объект останется на месте) или продлить срок жизни.
- Если срок истёк, но похоронить объект не удалось, например файл ещё открыт другой программой, он появится в «Burials that failed» на странице Decisions. Там указаны причина и время следующей попытки. Интервалы между попытками растут. После нескольких неудач Obituary ждёт вашего решения: «Retry» повторяет попытку немедленно, «Stop tracking» прекращает отслеживание и оставляет объект на месте.
- Пока Docker не запущен, кнопка одобрения предложения по контейнеру недоступна. Причина указана на карточке. Одобрить предложение можно после запуска Docker.
- Доверие к файлу `.obitrules` распространяется только на ту версию, которую вы видите в окне.
- Язык окна, значка в области уведомлений и контекстного меню задаёт `[ui] language` в `config.toml` (`auto`, `zh-CN` или `en`; `auto` выбирает язык Windows). Его можно сменить и в настройках.
- Окно доступно только для x64 и требует среды выполнения WebView2. Она входит в Windows 11 и установлена на большинстве компьютеров с Windows 10.

### Обновления

Более новую стабильную версию можно установить в Settings → About and updates. Obituary закрывает окно и программу в области уведомлений, обновляется через исходный канал установки (Scoop, WinGet или скрипт), затем пытается вернуть значок и снова открыть окно. Причины неудач и пути к журналам показаны на той же странице. Если вы распаковали программу вручную, скачайте новую копию со страницы выпусков.

### Восемь вариантов оформления

Выберите оформление в Settings → Appearance. Оно меняется сразу и только для окна на этом компьютере.

| Оформление | Описание |
|---|---|
| Календарь | Один столбец на день. Файл отображается в день захоронения или безвозвратного удаления. Перетащите файл на более позднюю дату, чтобы продлить срок жизни. |
| Одна строка | Одна строка ввода, управление с клавиатуры: найдите файл и нажмите Enter, чтобы воскресить его или продлить срок. |
| Туннель | Трёхмерный туннель времени: чем ближе файл, тем скорее истечёт его срок. Прокручивайте, чтобы перемещаться по времени. |
| Бдение | На тёмном фоне каждому файлу соответствует лампа. Чем она тусклее, тем ближе истечение срока. |
| Некрологи | Газетная полоса некрологов: колонки со шрифтом с засечками, при воскрешении появляется штамп. |
| Горизонт | Отслеживаемые файлы над землёй, кладбище под ней. |
| Mica | Оформление в стиле Windows 11 с боковой панелью. |
| Ночь | Спокойная тёмная тема с верхней панелью. |

## Контекстное меню

`obit init` по умолчанию устанавливает контекстное меню Проводника только для текущего пользователя. Щёлкните файл или папку правой кнопкой, выберите «Add to Obituary», а затем один из вариантов:

- **1 день / 7 дней / 30 дней**: объект похоронят по истечении срока, а до этого им можно пользоваться как обычно.
- **Bury now (recoverable)**: объект немедленно перемещается на кладбище и доступен для воскрешения в течение срока хранения (по умолчанию 7 дней).

Можно выбрать и добавить сразу несколько файлов. Уведомление покажет, сколько объектов добавлено, когда их похоронят и сколько не удалось добавить. В новом меню Windows 11 этих команд нет: выберите «Показать дополнительные параметры» или удерживайте Shift при щелчке правой кнопкой. `obit init --dry-run` выводит все пункты и их команды; `obit doctor` проверяет установку.

В macOS и Linux контекстного меню пока нет. Чтобы зарегистрировать объект, используйте `obit mark <path> 7d`; чтобы похоронить немедленно, `obit bury <path>`.

## Значки и меню

По умолчанию `obit init` настраивает все перечисленные элементы. Каждый можно отключить отдельно в Settings → Icons and menus:

| Переключатель | Что меняет |
|---|---|
| Значок в области уведомлений | Показывает значок Obituary. Если его скрыть, очистка продолжится. |
| Значок на панели задач | Занимает ли открытое окно место на панели задач. |
| Меню «Пуск» | Пункт «Obituary» в меню «Пуск». |
| Ярлык на рабочем столе | Ярлык «Obituary» на рабочем столе. |
| Контекстное меню | Пункт «Add to Obituary» в Проводнике. |

При установке `obit init --no-context-menu` пропускает контекстное меню, а `--no-shortcuts` — ярлыки в меню «Пуск» и на рабочем столе.

О датах захоронения, которые показывает Проводник, см. [правила для папок](./folder-policies#dates-in-explorer).
