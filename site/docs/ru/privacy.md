# Политика конфиденциальности

Реестр Obituary, кладбище, журналы и настройки остаются на вашем компьютере. Obituary не отправляет отчёты о сбоях, файлы, пути к ним или их содержимое.

## Статистика использования

По умолчанию статистика включена. Она нужна только для подсчёта активных установок и оценки распределения версий. При фактическом использовании Obituary может не чаще одного раза за 24 часа отправлять случайный идентификатор установки, версию, ОС, архитектуру, язык интерфейса и канал установки. Программа не отправляет файлы, пути или команды и не сохраняет IP-адреса и заголовки User-Agent. Отключить отправку можно командой `obit config telemetry off` или настройкой `OBIT_TELEMETRY=0`. В среде CI и при `DO_NOT_TRACK=1` отчёты не отправляются.

Сервер не хранит IP-адреса, строки User-Agent и исходные идентификаторы установок. Хеш, рассчитанный с отдельным ключом, позволяет связать отчёты одной установки, но не установить личность человека. Подробные данные о ежедневной активности удаляются через 400 дней. Для исключения повторов в долгосрочной перспективе сохраняются только хеш и даты первого и последнего наблюдения. Для каждого канала ведётся лишь суммарный счёт успешно отправленных отчётов. Панель статистики доступна только сопровождающим проекта после аутентификации.

При отключении отправки удаляются локальный идентификатор установки и ожидающие отправки отчёты. Проверка обновлений отключается отдельно.

## Проверка новых версий

- Не чаще одного раза в день Obituary запрашивает открытые сведения о последнем выпуске репозитория на `https://api.github.com`. Если GitHub не отвечает, программа обращается к `https://cn.obituary.woodfish.site/download/latest.json` на зеркале в материковом Китае.
- Запрос содержит только обычные для веб-запроса данные: ваш IP-адрес и заголовок User-Agent с версией Obituary, например `Obituary/1.0.0`.
- Автоматическую проверку можно отключить в любой момент: выключите «Check for updates automatically» в настройках окна или добавьте в `%APPDATA%\obituary\config.toml` следующие строки:

  ```toml
  [update]
  check = false
  ```

  После этого проверка выполняется только при запуске `obit update --check` вручную.

## Установка и загрузка

- Scoop, winget и установочный скрипт загружают архивы с [GitHub Releases](https://github.com/woodfishhhh/obituary/releases). При этом действует [положение GitHub о конфиденциальности](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- При выборе зеркала (`-Mirror cn`) файлы поступают с `cn.obituary.woodfish.site`. Для диагностики неполадок сервер ведёт обычные журналы доступа: время, IP-адрес и запрошенный URL.
- При выпуске GitHub Actions отправляет файлы на зеркало. Зеркало проверяет и раздаёт их самостоятельно и не пересылает ваш запрос на загрузку в GitHub.

## Подключение агентов

`obit init` изменяет только файлы конфигурации агентов на вашем компьютере, предварительно показывая план. Команда ничего не отправляет поставщикам агентов или кому-либо ещё.

## Сайт

- На сайте <https://obituary.woodfish.site/> нет скриптов аналитики или отслеживания. В материковом Китае сайт обслуживает наш сервер, в остальных регионах — GitHub Pages. Оба ведут обычные журналы доступа.
- Адрес электронной почты, оставленный на сайте, используется только для уведомлений о новых платформах и версиях. Он хранится на нашем сервере и не передаётся третьим лицам. В каждом письме есть ссылка для отписки.

## Контакты

Вопросы о конфиденциальности можно задать в [GitHub Issues](https://github.com/woodfishhhh/obituary/issues). О проблемах безопасности сообщайте в частном порядке, как описано в [SECURITY.md](https://github.com/woodfishhhh/obituary/blob/main/SECURITY.md).
